## Asking Questions

### Before Asking

1. **Search existing resources**:
   - Check the [troubleshooting guide](docs/TROUBLESHOOTING.md)
   - Search [GitHub Issues](https://github.com/tzervas/CogSynDelta/issues) for similar problems
   - Review the [documentation](docs/)

2. **Gather information**:
   - Your operating system and Python version
   - CogSynDelta version (`uv run python -c "import cogsyndelta; print(cogsyndelta.__version__)"`)
   - Full error messages and stack traces
   - Steps to reproduce the issue

### How to Ask

- **Be specific**: Include error messages, code snippets, and reproduction steps
- **Use appropriate channels**: Technical questions → GitHub Issues, general discussion → GitHub Discussions
- **Follow templates**: Use issue templates when available
- **Stay on topic**: Keep questions focused on CogSynDelta
