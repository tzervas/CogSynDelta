# Licence verification of previously UNVERIFIED catalogue entries

Session date: 2026-09-03. Analyst: Grok 4.6. Catalogue: `catalogue-2026-09-03.json` (159 entries).
Scope: every entry whose catalogue **verdict** is `UNVERIFIED` (37). Primary sources only — dataset content was not downloaded.
Method: re-fetch the upstream licence file/page (GitHub LICENSE, project site, paper data-availability, owner terms), not the HuggingFace mirror tag. On failure, try web.archive.org.
Verdict classes used: `PERMISSIVE` / `ATTRIBUTION` / `SHARE_ALIKE` / `NC` / `REFUSE-ND` / `REFUSE-TERMS` / `CONSENT_OPEN` / `STILL-UNVERIFIED`.
Operator rules applied: NC is admissible and propagates; REFUSE ND, research-only or non-redistributable terms, training/weight-release bans, distributors that disclaim owning what they distribute, and consent-revocable corpora unless EVAL-ONLY. The verdict rests on the primary text quoted, never on a mirror tag.

Verdicts: definite 17, still unverified 20. Breakdown: ATTRIBUTION 3, NC 1, PERMISSIVE 2, REFUSE-TERMS 6, SHARE_ALIKE 5, STILL-UNVERIFIED 20.

## Notes on method

- CourtListener `courtlistener.com/terms/` now 301s to `wiki.free.law/c/terms/courtlistener/courtlistenercom-terms-of-service-and-policies` (last modified 2026-08-05). That is the page prior passes could not get past CloudFront.
- Software Heritage TLS still fails a default trust store; the bulk-access ToU was read with `curl -k` against the same host, matching the earlier verifier.
- An accidental follow of `allenai.org/data/proofwriter` into a 214 MB dataset zip was deleted immediately; the zip was not inspected.
- Quora's release URL is excluded from the Wayback Machine; live fetches returned 403.
- No CogSynDelta file and no git repository was modified.
